## Currently Building

### 🧠 WorkSphere — AI-Powered Work Assignment System

WorkSphere is an AI-assisted work triage system that processes incoming work documents, extracts structured task information, and is being developed to provide **evidence-based employee recommendations** for managers.

The system is designed around a key principle: **the LLM does not decide who receives a task**. A transparent ranking system will make the recommendation, while the LLM is used for document understanding and evidence-based explanation.

### Current Pipeline

```text
Google Drive
     ↓
Team-scoped file ingestion
     ↓
Docling OCR / Document Extraction
     ↓
Gemini 2.5 Flash
     ↓
Structured task information
     ↓
MongoDB
```

### What is currently implemented

* **Role-based authentication** with JWT for Admin, Manager, and Employee
* Role-specific frontend panels connected to the real backend
* **Google Drive integration** using a backend service account
* Team-specific Drive folder isolation
* Document ingestion through a **manual Sync** workflow
* Python/FastAPI microservice for **Docling-based document extraction**
* Support for PDFs, scanned documents, DOCX, PPTX, XLSX, and images through Docling
* In-memory file processing without permanently storing original documents
* **Gemini 2.5 Flash** integration for structured task summarization
* MongoDB persistence for extracted tasks and metadata
* Idempotent synchronization using the Google Drive `fileId`
* Role- and team-scoped task retrieval

### Next Stage

* Generate embeddings from structured task information
* Store vectors and metadata in **ChromaDB**
* Retrieve similar resolved tasks with team and access-control filtering
* Rank employees using **similarity, expertise, and historical performance**
* Generate an LLM explanation grounded only in retrieved evidence
* Provide managers with **Accept / Override** controls

**Architecture:** `React` · `Node.js` · `Express.js` · `MongoDB` · `Python` · `FastAPI` · `Docling` · `Gemini` · `ChromaDB`
